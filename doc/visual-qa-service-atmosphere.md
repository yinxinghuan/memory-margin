# 服务点氛围家具视觉 QA

## 第一轮撤销

第一轮虽然碰撞和接近点通过，合成画面中的档案柜、等候椅和职员柜仍偏正面立面或混合透视。它们曾被错误标为准入；用户指出后已撤销。失败源图、平台任务和拒绝原因保留在素材目录与 `art-admission.md`；机械通过不能恢复视觉准入。

## 第二轮仍不合格

第二轮解决了正投和等比显示，却把轴向柜、旧式单人椅和低柜分散在房间边缘。单件透视成立，组合后仍像养老或普通办事机构；家具没有形成清楚的工作关系，题材身份也没有进入主要设备。此轮继续视为诊断画面，不作为最终签收。

## 当前修正

- 左侧收成一套“记忆接入工位”：记忆晶片缓冲柜、主终端与朝向终端的 45° 接入椅在视觉和碰撞上形成一组；椅子的黄铜接触导轨、状态节点和短光纤说明用途，不再作为普通等候座椅。
- 右侧收成“记忆处理 / 检修工位”：主终端与带记忆套、诊断探头和金属杯的维护台相邻，保留有人工作和维修的痕迹。
- 两张主终端升级为平台生成的 `service-console-v6`：深石墨面板、旧黄铜边轨、青色记忆波形与晶片槽统一全房设备语言，替换偏浅灰机构家具的 v5。
- 北墙改为冷蓝灰材质，两张木桌统一换成服务终端；服务说明牌固定在北墙。中央走道、门口和剧情接近点保持空。
- 当前运行的三件氛围资产为 `service-memory-chair-v2`、`service-memory-archive-v5`、`service-maintenance-console-v4`。生成成功但带假字、照片质感或方向不合的候选仍拒绝。
