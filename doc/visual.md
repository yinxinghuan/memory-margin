# 《记忆余量》（暂名）视觉方向与界面系统 · 试验版

## 视觉命题

玩家刚把意识上传，第一次在数字世界的居所醒来。这个世界应先像真实的生活空间：杯子、旧衣、门牌、邻居留下的纸条都有具体位置；只有在记忆断裂或所有权被触碰时，设施的冷光才显露出来。玩家记住的第一幅画面，是一段熟悉语音播到最后突然空白，桌上物件仍然完好。温柔的表面与消失的私人记忆形成第一层不安。

沿用已评审第六套“夜间城市蓝图”的布局语法，收敛成克制像素风。蓝图线只标实际门、路线和资料来源，不能把整个居住空间画成工程图。地图使用正交俯视；人物与物件采用统一像素采样，长对白与资料使用清晰的非像素正文字体。

## 空间、镜头与材质

- 首轮三个有用途的地点：转生居所（私人记忆）、公共走廊（邻里行动）、记忆服务点（制度留下的记录）。门、通道和可操作家具须由同一场景数据投射到图像、碰撞、引擎热点和地图。
- 固定正交俯视，不混用斜透视室内图。人物以脚底定位，桌、柜、人物遮挡依据落地深度；墙面为不会变化的背景，语音盒、回执、门、服务窗口和人物是独立状态物件。
- 纹理靠清楚的边缘、磨损和少量噪点表达生活痕迹。数字材质只在接口、记忆槽和登记屏上出现，避免整场景镜面金属或高亮霓虹。
- 白盒先验证两次往返、通行净宽和手机视口。生成或手工素材都须登记来源、尺寸、透明度、主体边界和准入状态；不能仅凭单张图好看就替换已准入素材。

## 色彩与字

| 角色 | 色值 | 用法 |
|---|---|---|
| 夜色 | `#0b1822` | 游戏外底、深处阴影 |
| 生活空间 | `#263b43` | 墙和家具主色，不把所有房间压成黑色 |
| 纸与旧物 | `#c8b99c` | 回执、布料、可触摸的私人对象 |
| 正文 | `#e8ebe3` | 面板正文，至少 16 CSS px，行距 1.55 |
| 次要文字 | `#a9bdc1` | 补充信息，不独占关键线索 |
| 可操作 | `#69c4c5` | 行动和接口，必须配文字或形状 |
| 未核对 | `#e2ad68` | 来源存疑，必须说明为什么 |
| 已确认 | `#9bc7a6` | 看过两处来源后的事实 |
| 失去与错误 | `#ed8f85` | 缺页、使用权代价、可恢复错误 |

标题使用端正、窄而不挤的无衬线字；正文与证据使用适合中文阅读的系统无衬线回退。数字、时间和回执编号用等宽字。像素字体只可用于极短设备编号，不能用于整段对话。所有文字中英双语时均须保持层级，不以降低字号解决溢出。

## 核心画面与信息层级

- **探索**：地图占主体，目标只写眼前动作，如“听完那段语音”。接近物件出现标签与单一行动按钮；提示不能挤动镜头。移动区和行动区都避开门与人。
- **首次缺页**：播放器先展示可理解的前半段，再发生可见/可听的短缺口。静音时仍有空白波形和“不完整”的文字，不能依赖声音独占线索。
- **资料阅读**：物件上的资料可以只读放大，清楚显示来源、时间与已知/未知字段；关闭后保持外层滚动、当前选择与人物位置。资料放大本身不提交结论。
- **人物与对话**：首次登场先看见外形和动作，再获得称呼。善意和恶意从说法与可回访行为之间的关系显现；人物面板不提前透露本性。
- **选择与后果**：在触及记忆使用权前，把保留、借出、可撤回性等本次真实条款并列写清；确认后回到地图看到至少一处状态变化。不可用抽象结算卡替代后果。
- **更长的世界观段落**：早餐便条先让玩家触碰转生后的感官生活，走廊告示展示别人的一格记忆难题，窗口说明牌才说出正式留存与借出规则。这三处可跳过，不在开场叠成术语页。
- **六秒预览**：第二段用邻居的无意哼唱、窗口可放大的播放记录与职员解释建立矛盾。关掉预览后，屏幕从青色条纹变暗并加斜线；追查账户后保留一小格琥珀色记录标记。两者都有明确文字状态和不同回访对白，不能只靠颜色区分。
- **地图和背包**：沿用档案交互与资料放大能力，但将词汇换成转生者已知的日常物件、回执和已见人物。未到过的地点不提前列出世界观术语。

## 界面几何与图标

面板平直、边角轻微切角，1px 分隔线和局部刻度来自登记设备；私人居所面板更安静，服务点刻度更密。主要按钮至少 44×44 CSS px，文字和图标同时表达作用。统一线性 SVG 图标体系，不用 Emoji、拟物发光圆按钮或透明玻璃大卡片。必要的状态区别同时用颜色、文字和结构表达。

## 动效和声音

常规靠近 120–180ms，读取确认 180–220ms；首次缺页用一次约 400ms 的静止和波形空位，不做频闪或持续扫描线。选择后的局部设施变化可以用 400–600ms 完成。尊重 `prefers-reduced-motion`：取消位移和闪动，保留文字、颜色和物件状态。音效轻且有限，缺页在静音下仍然可辨。

## 目标尺寸与验收

以平台内 390×844 为主，320×568 为窄屏复验。地图等比呈现，HUD、对白、档案阅读器和选择面板各自重排；不能只把整页缩小。另测英文长句、首次进场、一个人物初见、放大资料、选择前条款、选择后回访与错误恢复。外部访客栏仅作覆盖可用性检查，不决定平台内构图。

## 禁止漂移

禁止把旧街地图、黄雨衣、旧资料和旧结局换名复用；禁止将原“求救信号改道”占位故事接入本题材；禁止一进场出现容量、配额、机构、派系的术语清单；禁止将每个像素物件叠霓虹描边；禁止用随机谎言冒充人物复杂性；禁止用美术画出的门与实际引擎出口不一致。

## 当前状态

这是基于用户已选第六套风格的独立题材试验方向。当前居所、走廊、服务点与预览屏已在真实 renderer 运行；程序诊断图仍不是准入的正式角色造型或场景美术。长文字、静音和英文本地化的最终视觉评审仍待完成。
