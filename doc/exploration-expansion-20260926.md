# 七区域探索扩展验证

## 改动
正式区域从 3 增至 7。生活区连接走廊、邻居住所、修复铺和档案区；公开使用记录从服务点移到档案区，原服务点仍承担解释条款、核对与选择。新增四条可回看材料、两条事实驱动人物话题，开场先讲个人缺失，生活经历后再讲容量和权限。

目标栏提供阶段、地点、对象与目的，点击打开对应地图路线。未知地点可以看路线，首次到访前不可快捷移动。旧存档补新地图与事实，不覆盖既有故事选择。结尾明确七地点的范围与后续尚未开放。

## 证据
- 49 项测试通过，包含两种借用选择、两种预览选择、七区域可达性、前置条件、跨分支路线、旧档升级、资料回看。
- 技能世界校验：7 scenes / 28 targets / 12 directed portals / 107 cached textures；7 个 TMX 均有对象层。
- 浏览器普通操作：从旧完成档逐门进入四个新区域并执行新观察，邻居住所与修复铺返回；档案区完成后经地图跨分支回居所。热更新重载后地点与记录保留。
- 390×844：生活区体验、邻居住所、修复铺及修复铺比例复查。320×568：档案区、资料和七地点地图。发现地图卡片重叠后修改为相对高度，复查卡片均大于 44px 且互不重叠。
- 独立端口新英文旅程：简化开场、首次行动。截图见 `_qa/exploration-20260926/`。桌面响应式验证不等于 iPhone 实机性能验收。

## 美术来源与边界
本轮复用本游戏已有平台生成并处理的墙、门、地板、家具、主角和人物，不是新生图成功率试验。四个新地点独立装配，家具 footprint 与可行走路线共用数据。只增加正式固定内容，没有接入动态生成房间。

理解是否改善仍需用户实际试玩：comprehension unverified。不能以 49 个自动化测试或作者走通替代新玩家的理解。
