# 南墙渐变修正（2026-09-26）

## 原因与修改
原实现通过 Graphics 椭圆 cut() 产生硬边孔洞。改为缓存的径向 alpha 纹理：中心墙面不透明度 20%，半径 48 世界单位，前 58% 保持中心值，外圈渐变至完全不透明；中心在人物位置上方 28 单位。

每段裁切墙图单独换算纹理起点、缩放、anchor。只处理实际南墙，不把走廊侧门组件纳入；服务点门板保持独立，门旁墙体连续渐变。离开遮挡范围卸下遮罩，换场景销毁旧遮罩。行走只移动缓存遮罩，不逐帧生成图片。

## 验证
- 构建通过；45 项现有回归测试通过；凭据与 API base 审计通过。
- 浏览器实际操作：服务点近墙与远离（390×844）、换到走廊近墙（390×844）、换到居所近墙（320×568）。截图位于 `_qa/wall-soft-20260926/`。
- 本轮为桌面浏览器响应式验证，不等同于 iPhone 实机性能验收。
