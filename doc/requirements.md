# 《记忆余量》需求文档

## 1. Overview

近未来，意识上传让人获得数字永生，但长期保留记忆需要稀缺的存储空间。玩家是刚完成“转生”、开始数字生活的普通人，没有调查机构资源，也不了解记忆制度。从自身一段取不全的日常记忆出发，玩家在可步行的居住街区接触邻居、服务人员与记忆设施，逐步发现谁能保留记忆、谁在以善意名义取得别人的使用权。

本作以一章完整的连续探索和对话为主，可以随时暂停。单次体验约 20–30 分钟，不设倒计时。跨次保存地点、已见人物、已读材料、记忆状态与选择；再次进入从原处继续。本章先查清第一段记忆的去向，亲自看见留存位的代价，再处理一次未经授权的声音预览；完成后有可回看的章节结果。更大的记忆存储权之争和 C-09 身份属于后续故事。

核心玩法：在可行走街区亲手追查一段属于自己的记忆，核对人物说法与可见记录，作出有后果的选择，再回到相关地点看结果。

### 渐进揭示与首次理解

- 首个有效动作：在转生后的居所尝试播放一段熟悉的语音，听到结尾缺失；走近保存盒取出迁入回执。玩家先看到自己的问题，不先读世界史。
- 世界观介绍可以有更长篇幅，但每一段必须落在玩家可碰到的生活细节：居所里模拟的气味和家常物件、走廊里别人的留存难题、窗口里真实执行的条款。第一层只引入“缺页”；容量和使用权在玩家需要解释现象时逐步出现，不在开场同时介绍配额、价格、机构与派系。
- 首次无惩罚闭环为 `播放 → 看见/听见缺口 → 决定查看回执`。此后新玩家应能说出：眼前要找回或弄清缺失片段；反复做的是到现场查看、与人交谈、核对来源；进展是获得新材料、验证说法或改变设施状态，风险是失去对记忆的控制权。
- 前 10 分钟的假设是玩家只需理解“缺页”和“有人能决定它被谁使用”。第一次决定之后，才出现“预览和正式借用是两种不同权限”的第二层知识。是否真正理解必须由新玩家复述或行为验证，自动路线通过不算理解通过。

## 2. Visual Design

正交俯视、克制像素采样的近未来居住街区。世界首先像有人生活的地方：桌上私人物品、走廊、服务窗口和可识别通道；数字设施只有局部冷光。界面采用六套候选中的 `05-terminal`“夜间终端”：HUD、行动区、互动面板、背包/档案、资料放大、加载、错误与结果统一使用深绿单色检索语法；对白和长资料仍使用清晰的系统正文字体。首段记忆缺页通过事件音效、画面空位与完整的前半段内容表达。该方向已在 390×844 与 320×568 的真实运行画面中通过，见 `doc/visual.md`。

## 3. Game Mechanics

- 首轮空间为居所、公共走廊、记忆服务点，至少两处真实场景可往返；门、接近点、碰撞和返回落点同源。场景与美术不从旧街换名复制。
- 核心循环：走近具体对象 → 主动查看或交谈 → 获得有来源的短材料或实际状态变化 → 回访验证 → 选择下一行动。只读放大不提交证据或答案。
- 自己的语音缺页、迁入回执和服务点使用记录分批出现。可先问人或先查记录；关键结论至少有两种可见来源支持，不能只靠反转对白宣布。
- 至少有一位表面冷硬却采取保护行动的人、一位措辞体贴却隐瞒成本的人，以及一位确实可靠的人。名字仅在可见登场后进入人物页。迷惑性来自利益与信息选择，不靠无提示的随机撒谎。
- 第一项有后果的选择是是否让他人临时使用这段记忆，换取当前保留空间。具体条款和可撤回条件仍是设计假设；切片必须让玩家先看懂代价，不能强迫未获信息时不可逆同意。两种选择都改变至少一处可回访的设施或人物反应。
- 返家核对原语音时，播放器旁出现早晨早餐气味的短暂印象。玩家亲手尝试把它长期留下：若已保留原语音，唯一位置被占，只能当天暂存；若借出原语音，空位可收下这段印象。它不是替玩家改选，不给“保留”和“借出”同时领取全部好处；两路在同一设备上显示不同状态。玩家仍可继续查外放事件。
- 第一项选择后的回访引出第二段调查：邻居在走廊无意听过玩家私人语音的开头；服务点的预览记录显示，正式授权仍为空时，系统已经公开播放过 6 秒。玩家查记录、问窗口；还可回问值守人封签为何没拦住预览。两人的解释都必须和可见记录相互印证或冲突。
- 第二项有后果的选择是立即关掉公开预览，或允许再播一次来捕捉正在收听的账户号。前者阻止新的外放、保留已有匿名记录；后者获得一个账户号，但玩家事先知道会再暴露 6 秒私人声音。两路通过同一权威存档锁定，并在服务点屏幕及邻居回访中显示不同结果。没有倒计时，账户号只作为后续线索，不在本切片直接揭开身份。
- 居所、走廊和服务点各留一处可选的生活观察，补足转生后的日常与记忆稀缺性；这些观察不成为强制取证门槛。较长的世界观篇幅靠走动、观察、对白和后果组成，不用单页百科文本替代游戏过程。
- 切片只追踪这一段记忆的 `完整/缺页`、`保留/借用` 与玩家是否知道使用者；不引入大额货币、体力条、不断倒数的容量值或多层术语。更完整的容量经济待后续验证。
- 位置、事实、材料与选择由一个权威存档决定。内容生成只能填已建地点和角色允许的空位，不能发明通道、道具或权威事实；先完成固定作者版本，再尝试真正不同的调查行动。

### 待验证实验

1. 新玩家在首段操作后能否说出目标和下一步，且没有被术语淹没；无新玩家证据前标记 `comprehension unverified`。
2. 真实 RPG-JS 中完成两处以上场景往返、材料阅读、选择后回访和刷新恢复；背景、热点、碰撞与引擎位置一致。
3. 对同一人物提供说法与行为两条线索，观察玩家是否主动提出疑问；若只能靠作者解释，重写呈现。
4. 第五套“夜间终端”UI 在 390×844、320×568 和较长英文文案中能否兼顾明确操作反馈、生活化开场与长文可读。
5. 独立 agent 仅凭试用技能与本项目资产/状态合同制作一处新增可玩场景；记录缺失说明后再决定交接。

## 4. Controls

键盘 WASD／方向键移动，触屏摇杆或点地寻路，鼠标点击地面寻路。互动固定分三步：点击地图物件只把角色带到接近点；进入激活区后，底部行动按钮显示稳定目标名与“查看／交谈／前往”；再次按行动按钮或 E 才打开物件/人物内容，门则执行转场。靠近本身不弹面板、不提交行动。内容面板绑定打开时的目标，附近目标变化不能偷换内容；移动、点击空地、关闭按钮或再次按底部按钮会退出面板。对话及可滚动资料列表用 click，允许触屏滑过；只读资料可放大/缩小，关闭后保留外层选择与滚动。地图拖动不移动角色。触控目标至少 44×44 CSS px，关键动作可键盘完成。

## 5. Win / Lose Conditions

本章完成条件是查清第一段记忆的去向、作出知情的使用权选择并回访语音，随后查明未授权预览、作出第二项知情选择并回访邻居。早餐印象为可选后果观察，不成为通关门槛。没有死亡、得分、Game Over 或倒计时。暂时判断错误可继续找证据；两项最终选择的后果随存档保留。完成后从权威事实生成只读章节回顾，明确本次保留了什么、暴露了什么、下一步仍未知；玩家能关闭回顾继续探索，刷新后仍可再看。页面关闭后从上一次已确认状态继续。C-09 身份未揭晓是本章结尾的明确悬念，不是缺失的完成状态。

## 6. Sound Effects

背景使用平台媒体服务生成的 60 秒低存在感环境音乐，玩家第一次操作后开始循环；不自动抢占浏览器声音权限。记忆裂隙使用平台生成的短事件音效，普通接近、读取、来源矛盾、关键选择和章节完成继续用短促 Web Audio 提示。首段语音没有使用真人配音，以文字、波形和停顿叙事，不把提示音称作配音。统一静音按钮会暂停音乐和事件音效；静音时仍能从画面和文字理解所有线索，音频失败不阻断游戏。
