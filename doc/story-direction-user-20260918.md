# 第二款游戏的故事方向（用户输入，待旧街收口后落实）

近未来，AI 与相关科技使人能把意识上传到线上，选择“数字永生”。永生者发现记忆存储是稀缺且珍贵的资源，围绕谁能保留、占用或支配记忆容量发生争夺。游戏应让玩家亲历这种资源竞争造成的现实后果。

人物关系需要比《旧街最后一封信》更难凭第一印象判断：看似坏却有善意的人、以好人面目行恶的人，以及真实可靠的好人同时存在。对白允许误导和隐藏动机，让玩家感到这个世界的恶意；关键判断必须能通过可发现的行动与证据复核，避免只靠反转台词宣布真相。

## 主角方向更新

曾考虑让玩家扮演替人找回记忆的调查员。用户担心这个身份拥有过多资源、缺少自己的危机感，并进一步提出：改从一个刚完成“转生”的普通人的经历进入故事，让玩家一点点感受和学习这个高概念世界，不在开场灌入大量必须记住的设定。用户已确认“转生”指刚把意识上传、开始数字生活；“转身”是口误。此前按件接活的调查员及其设备/权限/额度方案现为**弃用候选**，不能作为新游戏主角或已确认数值合同。

正式需求应从普通人上传后的第一段可操作经历写起：先遇到一个眼前问题、做出一次选择并看到后果，再逐步揭示记忆容量、永生资格与争夺规则。人物的善恶反转要从可复查的行为和证据建立，避免用长篇说明或一段台词一次性交代世界。

此前求救线路故障故事是先前试验占位设定，不能当作用户确认的剧情。已写的基础模块与地图白盒只是暂存工作，不代表成品剧情方向。
