# 《记忆余量》技能复用评估

本次目标是用当前技能改造旧项目、暴露复用缺失并发布可玩的验证版。不是继续为单款游戏无限精修，也不是一次从零、零参考的完整美术稳定性实验。

## 实际使用结果

| 能力 | 本次结果 | 是否仍靠项目补救 |
|---|---|---|
| RPGJS 空间运行时、纹理缓存 | 三室空间层和人物进入 RPGJS/Pixi，46 静态层，单 canvas；取消逐帧场景 DOM 绘制 | 是。项目静态层烘焙和局部前景 stencil 尚未成为独立通用装配工具 |
| 平台 GPT 素材生产 | 本轮 41 请求；人物根图、门墙 text-only，动作与肖像有记录地使用同轮 edit | 提示词不能保证一次合格。错误朝向、相同步相和门下端收窄仍需检查和纠正；不提供虚构的一次成功率 |
| 主角与 NPC 比例、动作 | 同格、同脚线、约 71 世界单位可见高；主角四向接触相目检，NPC 按角色实际巡游方向制作 | 共用显示框不足以验收；动作采样曾出现隔帧抽样只剩站姿的假阴性，已写回技能 |
| 厚墙、门洞、遮挡 | 新正侧门和墙等比处理；侧墙来自顶盖切片；南墙局部露出门口人物 | 曾残留旧门框、错误尺度。需要在真实 renderer 检查门口到达和人物离开后两种状态，已写回技能 |
| NPC 接近与交谈 | 两步交互、面向、巡游、作者话题及真实自由输入 | 第 17 步返场时目标走动挡住旧路径。独立 approachingTarget 等待/取消策略已修复并固化合同 |
| 地图、主题背包、资料放大 | 05-terminal；地图直接读取 world 布局，未知房间不泄漏；物品/线索/人物分区 | 文档需持续强调主题化结构，不是复制同一游戏的固定栏目；人物姓名/身份布局已修 |
| 对话与语言 | 渐进显示、网络失败保留草稿、关闭取消、真实请求和 mock 分开取证；非中文系统英文 | 旧版假自由输入及默认语言问题已改；模型没有修改剧情的权限 |
| 权威故事与恢复 | lend/trace 与 keep/stop 各 23 次操作完整走通，刷新恢复 | 测试使用合成热点选择、真实引擎走路和真实 UI 提交；不当作触屏命中或玩家理解证据 |

## 尚未解决的技能缺失

1. **参数化场景生产工具不足。** 合同与检查器齐全度提高，但烘焙、裁切、事件注册、局部遮挡仍需接收 agent 编写适配；不应把本项目实现直接称为可移植完成。
2. **美术稳定性不能由规则数量证明。** 41 次请求含根图、派生与纠正，不能当成 41 次同条件试验。根图与同轮 edit 应分开统计，下一次独立制作要记录逐类首轮准入率和纠正次数。
3. **最终视觉签收依然依赖人工。** 检查器可拦非等比拉伸、错误脚点、缺文件和比例偏差，无法可靠判断迈步自然、正投影正确或主题气质一致。
4. **手机性能与输入证据不足。** 桌面持续输入没有观察到持续恶化，但不是 iPhone AlterU 性能或原生键盘通过。
5. **交付包独立检查的覆盖有限。** ZIP 在临时目录完成 48 项机械检查，未让接收方 agent 仅凭包完成一个新游戏并由人验收；不能宣布稳定交接已完成。
6. **本次不是全资产重新生成。** 保留了该游戏原有的部分地板、家具、资料、音频；新旧来源必须可追踪。保留素材不算新模型或无历史参考生成能力通过。

## 已回写

共享技能新增了巡游目标接近期间等待/取消规则、真实相位采样、门墙同源尺度与实景二次复拍规则；上一阶段补充真实自由输入、实际 renderer 归属、可重复裁切和国际产品语言边界。本次审核包在 doc/skill-handoff/；不含部署凭据。

## 结论

技能能够指导完成可玩的改造，但还不是“交给任意 agent 就能稳定一次生成合格游戏”的成品方案。此次发布验证运行链路与可复用合同；后续优先补通用装配工具和独立接收方试验，不继续在本游戏堆装饰来掩盖技能缺失。
