# 《记忆余量》技能复验与更新

用户目标：用当前技能重新更新第二款记忆题材探索 RPG，同时验证技能的完整性。保留现有未提交 QA 文件、剧情分支、旅程存档与 05 夜间终端风格。

## 产品合同

- 面向国际用户；故事仍是虚构的近未来数字居住区，不改为金融游戏的纽约背景。中文是协作语言。
- 普通人刚上传意识，逐步认识记忆保留、借用与授权制度。第一章约 20–30 分钟。
- 英文作为非中文系统的默认语言；中文系统使用中文。
- 环境素材纯文字生成；人物可从本轮新身份图派生，逐项记录来源。不得使用旧游戏图片作为隐藏参考。
- 平台统一媒体接口，显式 gpt-image-2.5-sunburst / high / opaque。模型名称为平台别名。

## 角色与文化一致性

故事是国际化的虚构数字居住区，不从工作语言推断国别。保留邻居、值守人、窗口职员的剧情身份和首次介绍顺序，本轮常用称呼统一为 Mara / 玛拉、Elias / 伊莱亚斯、Imani / 伊玛尼；中英文故事与档案同步。角色年龄和职业轮廓明确，不用外貌宣称国籍。新根图从文字生成；动作和肖像只引用各自同轮身份。职员有单侧胸牌，右向单独生成，不能整身镜像换边。
